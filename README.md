# AgriSense

Project workspace for the AgriSense frontend, backend, machine-learning modules, database assets, tests, and documentation.

## Structure

- `frontend/`: React application source and public assets
- `backend/`: API application and supporting modules
- `ml/`: disease, soil, and crop recommendation workspaces
- `database/`: migrations and seed data
- `tests/`: backend, ML, and integration tests
- `docs/`: architecture, API, and dataset documentation
